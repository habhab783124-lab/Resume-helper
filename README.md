# 拾阶 Resume Helper

面向应届毕业生的求职准备工作台课程项目原型，围绕个人资料、简历、岗位探索和模拟面试组织页面。

## 页面

- 工作台：求职准备进度、待办事项和岗位推荐
- 个人资料：求职意向、教育、技能与项目经历
- 材料整理：文件选择、项目经历粘贴和材料列表
- 简历工作台：简历编辑、预览和浏览器打印
- 岗位匹配：上海演示岗位、关键词搜索和收藏
- 模拟面试：逐题练习与浏览器语音试听
- 面试报告：综合表现、逐项建议和问题回顾

## 本地预览

需要安装 Node.js。在项目根目录运行命令 node preview-server.cjs，然后打开 <http://127.0.0.1:4173>。项目无需安装 npm 依赖。

## 当前原型范围

本仓库目前提供静态前端原型，页面由 HTML、CSS 和原生 JavaScript 构成。登录、材料、岗位、AI 建议和面试报告使用演示交互与示例数据，尚未连接账号、Java 后端、大模型、真实招聘源或 TTS 服务。文件选择仅在页面展示文件名，不会上传或解析。语音试听使用浏览器内置语音能力。

后续可由 Java / Spring Boot 提供 HTTP API，逐步接入登录、材料解析、简历生成、岗位匹配与面试服务。
