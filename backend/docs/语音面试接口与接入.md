### 已实现的应用接口

| 方法 | 路径 | 结果 |
| --- | --- | --- |
| GET | `/api/interview-speech/capabilities` | ASR/TTS 本机配置与工具开关，120 秒 / 5 MiB；不验证授权/额度 |
| POST | `/api/interviews/{id}/questions/{questionId}/speech` | 服务器已生成题目的 MP3；失败为 JSON 错误 |
| POST | `/api/interviews/{id}/transcriptions` | multipart `file/questionId/requestId`；回带三个 ID、text 与 durationMs，不提交回答 |

材料、面试、ASR、TTS、报告统一通过 `UserContext` 读取 `X-User-Id`，当前前端为 `demo-user`。该请求头可伪造，只用于演示数据分区，不是正式认证；cookies/HTTP session ID 不决定归属。语音请求不发送文本模型设置或火山密钥，语音密钥只在后端。

### 正式后端配置与部署

Spring Boot 与冒烟脚本不会自动读取根目录 `.env`。将 `VOLC_SPEECH_API_KEY=...` 等配置保存为 shell 环境变量，或在受信任的本地 `.env` 保存后，从仓库根目录启动：

```bash
set -a
source .env
set +a
cd backend
mvn spring-boot:run
```

不要把语音 key 写为 `VITE_*`，也不要提交 `.env`。本轮检查时磁盘上的 `.env` 为空，当前账户调用尚未验证。

正式配置为 `app.interview.speech.*`，独立于文本模型配置。

| 变量 | 正式后端默认 / 用途 |
| --- | --- |
| `VOLC_SPEECH_API_KEY` | 空：ASR/TTS 关闭；只在服务端注入 |
| `VOLC_ASR_RESOURCE_ID` | `volc.seedasr.sauc.duration`，以账户授权为准 |
| `VOLC_TTS_RESOURCE_ID` | `seed-tts-2.0` |
| `VOLC_TTS_SPEAKER` | `zh_female_vv_uranus_bigtts`，须验证音色权限 |
| `FFMPEG_PATH` / `FFPROBE_PATH` | `ffmpeg` / `ffprobe`，可设绝对可执行文件路径 |

smoke 脚本默认 ASR resource 仍是 `volc.bigasr.auc_turbo`，真实联调须显式配置账号实际授权的 `VOLC_ASR_RESOURCE_ID`，不能把默认值当作账户权限证明。

部署进程的 PATH 必须能找到真实可执行工具；仅安装文件或在个人 shell 能运行不够。ASR 开关需 key、资源与两个可执行工具，TTS 需 key、资源和音色；能力接口不调用厂商，不能确认权限/额度。Windows PATH 支持 .exe/.cmd/.bat 探测，但真实 Windows 转码仍须验收。

```bash
ffmpeg -version
ffprobe -version
curl http://localhost:8080/api/interview-speech/capabilities
# 仓库根目录验证缺配置行为，不输出任何 key
env -u VOLC_SPEECH_API_KEY python3 backend/tools/speech-smoke.py
# Node 24+, Chrome, ffmpeg；不使用真人麦克风或外部服务
cd frontend
node tools/check-interview.mjs
```

浏览器录音入口须 HTTPS 或 localhost，普通 LAN HTTP 可能没有 mediaDevices。应用录音上限为 **5 MiB / 120 秒**；后端真实探测并转为 16 kHz 单声道 PCM16 WAV，不信任扩展名或 MIME。材料仍为 **10 MiB**，全局 multipart 为文件 `10MB` / 请求 `12MB`。

后端 FFprobe/FFmpeg 每次预算各 10 秒，ASR 总预算 60 秒，TTS 30 秒；前端转写默认等待 **90 秒**，覆盖规范化和网络余量，反向代理超时至少 **100 秒**。取消会终止前端等待并丢弃迟到结果，但不能承诺厂商已执行的请求不收费。没有自动付费重试；识别失败或取消保留录音，能力重试保留已有录音/预览。

403/资源或音色错误需核查账户权限，不能通过能力开关判断。429 为应用或厂商繁忙；当前后端全局最多 2 个语音请求、同 owner 最多 1 个。409 表示题目/状态/pending 变更；语音 404 本身不清空面试。5000 字以上转写完整保留，编辑精简后才可提交。

本地录音、预览、未提交草稿刷新后丢失；已提交面试记录一天内可恢复，后端重启失效。材料、简历、面试与报告共用当前标签页的文本模型设置。报告只接受 FINISHED，模型失败可返回明确标注的规则报告；报告路由只传 sessionId。详见[文字面试接入](文字面试接口与接入.md)。

## 冒烟脚本与历史账户证据

`backend/tools/speech-smoke.py` 使用环境变量中的语音 key，合成固定问题并落地 MP3，再送 ASR。只用 Python 标准库；TTS/ASR 超时分别为 30/60 秒。真实运行会产生费用，CI 不运行；不写入或打印密钥。

```bash
# 先在当前 shell 安全配置语音 key，并显式设置账户授权资源
export VOLC_ASR_RESOURCE_ID='账户实际授权的资源'
python3 backend/tools/speech-smoke.py
# 仅识别已经转为 WAV 的本地录音
python3 backend/tools/speech-smoke.py --asr-file out.wav
# 指定音频落地路径
python3 backend/tools/speech-smoke.py --output /tmp/question.mp3
```

`--asr-file` 原样发送文件字节，不能仅改扩展名。独立采样的转码命令：

```bash
ffprobe -v error -show_entries format=duration -of json recording.webm
ffmpeg -nostdin -hide_banner -loglevel error -y -i recording.webm \
  -map 0:a:0 -vn -ac 1 -ar 16000 -c:a pcm_s16le out.wav
```

官方协议参考：[录音文件极速版识别](https://docs.volcengine.com/docs/DoubaoVoice/LargemodelrecordingfileLiterecognitionAPI?lang=zh)、[单向流式语音合成](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-text-to-speech-http?lang=zh)。当前适配器使用固定 openspeech 端点与 X-Api-Key，不支持旧版双 key 凭据。ASR 校验 HTTP 状态及业务状态；TTS 解码逐行 JSON 音频片段，收到成功结束事件才返回完整 MP3。实时对话、WebSocket、流式字幕、声音克隆不在本期范围；报告不评价发音、情绪或节奏。

以下保留 **2026-10-13 旧环境/特定账户**的证据，仅作排查背景，不是本轮复测：

| 项目 | 当时结果 / 证据边界 |
| --- | --- |
| TTS → ASR | 脚本退出 0，合成的 Redis / Spring Boot 问题被正确转写 |
| TTS 授权与音色 | seed-tts-2.0、zh_female_vv_uranus_bigtts 可用；耗时 1.1–1.3 秒 |
| 合成 MP3 | ffprobe 确认为 MP3，约 35 KB、4.272 秒、24 kHz 单声道；**未人工试听** |
| ASR 资源 | volc.bigasr.auc_turbo 当时未授权；volc.seedasr.sauc.duration 当时调用成功 |
| ASR 耗时 | 4.3 秒样例约 0.5–0.66 秒；137.64 秒旧浏览器录音约 3.8 秒，不能推算当前 120 秒耗时 |
| Chrome 实录 | WebM/Opus，自然口语成功转写；137.64 秒 / 4.2 MiB 样本用于旧协议检查，超出当前 120 秒限制 |
| 尚无历史证据 | Safari、真实静音、120 秒页面自动停止、完整页面厂商流程与实际用量 |

历史未授权响应为 403 + 45000030，key 无效或平台错误为 401；资源回显不能区分拼错与未授权。授权、额度、音色以当前控制台与真实调用为准；请求 ID / X-Tt-Logid 可用于排查，不记录密钥。

旧 WebM 产物可能没有容器 duration；FFmpeg 可解码后验证真实时长。120 秒 16 kHz 单声道 PCM16 WAV 约 3.66 MiB，121 秒仍低于 5 MiB，所以字节上限不能替代时长限制。当前后端已拒绝超时长，前端也自动停止。旧本地 stub 覆盖过 19 个冒烟协议错误场景；当前 Java 协议、规范化与 UI 回归测试见文首。任何本地模拟都不能证明真人音质或厂商准确率。
