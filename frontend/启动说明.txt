拾阶 · 求职工作台前端

本目录是基于 Vue 3 和 JavaScript 的前端工程，工作台页面沿用 prototype-static 中的视觉原型，并已拆分成多个 Vue 页面。

运行步骤：
1. 安装 Node.js 18 或更新版本。
2. 在 frontend 目录打开终端，运行 npm install。
3. 运行 npm run dev。
4. 打开终端显示的本地地址，默认通常是 http://localhost:5173/。

当前页面以静态展示为主。登录页的“体验演示工作台”可以进入工作台；登录、材料上传、AI 简历修改、岗位匹配、语音面试等业务尚未连接 Java 后端。

主要页面：工作台、个人资料、材料整理、简历工作台、岗位匹配、模拟面试、面试报告。
