# 面试聊天、历史与故障流程验收

**验收日期：** 2026-10-17
**结果：** 自动化回归通过；真实厂商、真人麦克风和目标系统仍待 T40/T41。
**运行方式：** `cd frontend && CHECK_ARTIFACT_DIR=../docs/interview-chat-artifacts node tools/check-interview.mjs`

## 环境与范围

- 本地 Vite 页面、项目内 mock API 和 Chrome 假麦克风；无真实简历、账号或厂商凭据。
- 桌面视口 1440×900；窄屏视口 390×844。
- 检查准备、会话恢复、文字与语音回答、自动转写、朗读、追问、算法/专业案例专项题、结束选项、完整/部分报告、评分重试、打印/PDF 导出及本地草稿；并注入生成重试、预算耗尽、不可重试配置错误、保存/结束响应丢失及录音/转写/生成中结束。
- 页面朗读和语音识别由本地 mock 服务模拟，故不代表实际厂商、真实麦克风权限或设备兼容性。

## 结果摘要

- 98 项浏览器断言全部通过；脚本的 `validation.json` 保存检查列表、模拟请求、确认框和错误信息。
- T20 桌面与移动端布局通过，无横向溢出；结束弹窗与信息抽屉的 Escape 关闭和焦点返回通过。
- 保存回答后出题失败保留回答；用户结束不会追加出题；算法题与非编码专业案例均完成 13 个主问题，追问不计数。
- 报告评分、部分失败重试、打印/PDF 导出和草稿恢复路径通过。
- 出题最多自动重试五次（最多六次尝试），120 秒总预算到期停止；配置错误不自动重试，用户可手动继续生成。
- 保存响应丢失后以相同幂等键恢复已提交回答；结束响应丢失后读取会话状态并进入报告。结束操作覆盖录音中、转写中、首题生成中与重试等待中。
- 草稿存储不可用时文字回答仍可继续；评分不可用时保留待评分状态。语音状态在 Vue reactive 解包时曾导致结束弹窗未取消录音/ASR，已修复并纳入回归。
- T23 来源入口：已有材料直接预览且不重传；已保存简历版本直接预览且不触发抽取；岗位入口带入超过列表摘要长度的完整 JD，并保持简历来源需明确选择；直接入口可用。
- T38/T39 历史：显示实际 expiresAt；删除触发原生确认框，向 API 发出 DELETE，成功后移除卡片，刷新后记录仍不再显示。
- `npm test`：209 项通过；`npm run build`：通过。
- 后端完整 Maven 回归：378 项通过（0 失败、0 错误、0 跳过）。

## 运行边界与未验证条件

- 新会话快照默认保留 30 天，`expiresAt` 创建时冻结；旧会话期限不追溯延长。文件存储仅支持单实例；存储重启恢复由后端测试覆盖，历史页刷新由浏览器脚本覆盖，不代表多副本协调或异机备份。
- 迟到语音/生成响应隔离由前端单测及后端集成测试覆盖；本次浏览器脚本没有模拟真实厂商在客户端取消后继续返回。
- 页面使用 mock API 与假麦克风。真实厂商凭据、真人麦克风权限、Edge/Safari/Windows 兼容性留待 T40/T41 验收。历史退出登录后的真实草稿清理和厂商迟到响应也不由此模拟验收替代。

- 只更新模拟面试专属组件与必要的语音/面试 API 包装：入口检查、准备页、消息、顶部栏和回答输入栏；未调整全局导航、设置、简历、材料、岗位或报告页面。
