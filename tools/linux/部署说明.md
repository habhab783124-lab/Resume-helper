# 拾阶求职工作台 · 部署到 Linux 服务器

> 面向：有一台 Linux 云服务器（独立公网 IP）的情况。
> 本包**自带 JRE 17**，服务器上**什么都不用装**，也不需要 Docker、Node、Maven、数据库。

---

## 一、包里有什么

```
拾阶-Linux部署包\
├── start.sh                      ← 启动脚本
├── resume-helper.service         ← systemd 服务单元（推荐用它常驻）
├── 部署说明.md                    ← 你正在看的这份
├── app\
│   ├── resume-helper-backend-0.1.0-SNAPSHOT.jar    后端 + 前端（一个进程全包）
│   └── webapp\                                      前端页面
└── jre\                          ← 便携版 Java 17（Linux x64），不用在服务器上装 Java
```

**关键设计**：后端自己就把前端页面一起提供了，所以
**只有一个进程、一个端口、同源、没有跨域**。
不需要 Nginx，不需要配 CORS。

> 注意：`jre/` 是 **Linux x86_64** 版本。如果你的服务器是 ARM（aarch64），
> 需要换成对应的 JRE——见文末「换 ARM 服务器」。

## 二、部署五步

### 1. 上传到服务器

在你自己的电脑上执行（把 IP 和用户名换成你的）：

```bash
scp -r 拾阶-Linux部署包 root@你的服务器IP:/opt/resume-helper
```

或者用 **WinSCP / FileZilla / 宝塔面板** 传上去，放到 `/opt/resume-helper`。

> 上传前先在服务器上建目录：`mkdir -p /opt/resume-helper`

### 2. 试跑一下（前台，先确认能起来）

```bash
ssh root@你的服务器IP
cd /opt/resume-helper
sh start.sh
```

看到这样的输出就对了：

```
============================================================
  拾阶求职工作台
============================================================
  Java : ./jre/bin/java
  Port : 8080
  堆   : 768m
  访问地址： http://<这台服务器的IP>:8080/
============================================================
...
Tomcat started on port 8080
```

**看到 `Tomcat started on port 8080` 就说明成功了。** 按 `Ctrl+C` 停掉，进入下一步。

### 3. ⚠️ 放行端口（最容易卡住的一步）

云服务器有**两层**防火墙，**两层都要放行**，少一层就连不上：

| 层 | 在哪改 | 做什么 |
|---|---|---|
| **① 云平台安全组** | 雨云控制台 → 你的服务器 → 安全组 / 防火墙 | 添加入站规则：**TCP 8080** 放行 |
| **② 系统防火墙** | 服务器上执行 | 见下 |

系统防火墙按发行版选一条：

```bash
# Ubuntu / Debian（ufw）
sudo ufw allow 8080/tcp
sudo ufw status

# CentOS / Rocky（firewalld）
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload

# 如果两个都没装，就不用管
```

> **为什么用 8080 而不是 80**：国内服务器用 80/443 端口配域名通常需要**备案**。
> 直接用 `IP:8080` 访问一般不需要，演示够用。

### 4. 用 systemd 常驻（关键）

**直接在 SSH 里 `java -jar` 有个致命问题：你一断开连接，进程就被杀掉了。**
用 systemd 托管才能开机自启、挂了自动重启。

```bash
# 1) 把服务单元里的路径改成你的实际路径（默认就是 /opt/resume-helper，一般不用改）
sudo cp /opt/resume-helper/resume-helper.service /etc/systemd/system/

# 2) 如果路径不一样，编辑一下
sudo nano /etc/systemd/system/resume-helper.service

# 3) 启用
sudo systemctl daemon-reload
sudo systemctl enable --now resume-helper

# 4) 看状态
systemctl status resume-helper
```

看到 `active (running)` 就成了。

### 5. 访问

浏览器打开：

```
http://你的服务器IP:8080/
```

登录用演示账号：

| 邮箱 | `demo@resume-helper.cn` |
|---|---|
| 密码 | `ResumeDemo2026!` |

## 三、日常运维

```bash
systemctl status resume-helper        # 看状态
systemctl restart resume-helper       # 重启
systemctl stop resume-helper          # 停止
journalctl -u resume-helper -f        # 实时看日志
journalctl -u resume-helper -n 200    # 看最近 200 行
```

改端口或内存：编辑 `/etc/systemd/system/resume-helper.service` 里的
`Environment=PORT=` 和 `Environment=JVM_MEM=`，然后：

```bash
sudo systemctl daemon-reload && sudo systemctl restart resume-helper
```

**别忘了安全组也要跟着放行新端口。**

---

## 四、内存怎么设

| 服务器内存 | `JVM_MEM` 建议 |
|---|---|
| 512 MB | `320m`（偏紧，解析大 PDF 可能 OOM，量力而行）|
| 1 GB | `384m` |
| 2 GB | `768m`（默认值，够用）|
| 4 GB+ | `1g` 或更多 |

默认是 `768m`，1GB 及以下的机器**务必调小**，否则系统会因内存不足杀掉进程。

## 五、出问题了怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 浏览器"无法访问此网站" | **九成是防火墙没放行** | 检查安全组和系统防火墙**两层** |
| `systemctl status` 显示 `failed` | 启动报错 | `journalctl -u resume-helper -n 100` 看原因 |
| 启动后立刻退出，日志显示 `OutOfMemoryError` | 堆太大或太小 | 调 `JVM_MEM` |
| 端口被占用 | 8080 被别的程序占了 | 改 `Environment=PORT=8081`，并放行新端口 |
| 中文变成乱码 | 服务器 locale 不是 UTF-8 | `start.sh` 里已经带了 `-Dfile.encoding=UTF-8`；确认用的是 `start.sh` 而不是自己敲的 java 命令 |
| 简历页没有电话邮箱 | **部署的版本较旧** | 那三个字段是后加的，用最新的包 |
| 材料页说"没有 AI token" | **这是预期行为，不是故障** | 在岗位匹配页顶部填自己的 DeepSeek token |

## 六、几件要提醒的事

1. **不要在这台机器上填真实个人信息**（真实姓名/手机/邮箱）。
   演示账号是写死在前端代码里的**公开账号**，任何人从 GitHub 都能看到。
   而且后端目前**没有真正的身份认证**——身份靠请求头 `X-User-Id` 声明，
   **客户端可以伪造**。放到公网上，别人改一下这个头就能读走你的数据。
   > 所以要**等 P0 的身份认证做完**再把真实信息放上去。
   > 现在这样部署，适合**演示**，不适合**真实使用**。

2. **数据存在本机磁盘**：`/opt/resume-helper/app/data/`
   里面是上传的简历原件、画像、简历版本。备份就备份这个目录；
   要清空就 `systemctl stop resume-helper && rm -rf app/data && systemctl start resume-helper`。

3. **语音面试需要额外装 ffmpeg**，并且要有火山引擎语音控制台的 API Key：
   ```bash
   sudo apt-get install -y ffmpeg        # 或 sudo yum install -y ffmpeg
   ```
   **不装也不影响文字面试**，语音相关能力会自动关闭并在页面上说明。

4. **没有 HTTPS**。用 `http://IP:8080` 访问，浏览器会提示"不安全"。
   演示可以接受；要上 HTTPS 就需要一个域名（国内域名要备案）+
   Nginx 反代 + Let's Encrypt 证书。

## 七、换 ARM 服务器（aarch64）

先确认架构：

```bash
uname -m          # x86_64 就是本文档适用的；aarch64/arm64 才需要换
```

如果是 ARM，把 `jre/` 换成 ARM 版：

```bash
cd /opt/resume-helper
rm -rf jre && mkdir jre
curl -L -o jre.tar.gz \
  "https://mirrors.tuna.tsinghua.edu.cn/Adoptium/17/jre/aarch64/linux/OpenJDK17U-jre_aarch64_linux_hotspot_17.0.20.1_1.tar.gz"
tar -xzf jre.tar.gz -C jre --strip-components=1
./jre/bin/java -version
```

> 上面用的是清华镜像（国内快）。文件名里的版本号如果变了，
> 去 `https://mirrors.tuna.tsinghua.edu.cn/Adoptium/17/jre/aarch64/linux/` 看一眼实际文件名。

**jar 不用换**——它是纯 Java，没有任何本地库（已核实过）。
